# 用户手册(User Guide)

> 状态:v0.2.0。面向使用者,说明界面布局、全部操作方式与常见问题。
> 界面或交互变化时须同步更新本文档与 [CHANGELOG.md](../CHANGELOG.md)。

## 1. 启动

在项目根目录执行:

```powershell
pixi run run
```

启动后出现主窗口(默认 1280×720),界面为简体中文。

## 2. 界面布局

| 区域 | 位置 | 内容 |
| ---- | ---- | ---- |
| 工具栏 | 顶部 | 打开文件、录音、播放、放大 / 缩小按钮、当前倍率 |
| 文件列表 | 左侧面板 | 会话内所有已导入的文件与录音,点击切换,底部有"添加..."按钮 |
| 曲线视图 | 右侧主区域 | 音高曲线、时间/频率网格、选区高亮、播放头 |
| 控制栏 | 底部 | 缩放滑块(0.25×–16×)、当前播放位置 |
| 状态栏 | 最底部 | 加载 / 录音 / 播放的状态与结果提示 |

**曲线视图图例**

- 蓝色实线:发声帧的基频(F0)曲线;
- 灰色虚线(贴着底部):该时间段未检测到发声;
- 浅蓝色高亮矩形:当前选区;
- 红色竖线:播放头(播放时出现)。

## 3. 导入音频

三种方式任选:

1. 菜单栏/工具栏点击 **打开文件**(快捷键 `Ctrl+O`),可一次选择多个文件;
2. 点击左侧面板 **添加...** 按钮;
3. 把音频文件从资源管理器**拖拽**到主窗口或曲线视图上。

支持格式:`wav`、`flac`、`mp3`、`m4a`、`aac`。
(wav/flac 保留原采样率;mp3/m4a/aac 会经 ffmpeg 统一转为 16 kHz 单声道。)

加载完成后:

- 曲线视图立即显示该文件的音高曲线,标题为文件完整路径;
- 状态栏显示 `已加载: <路径> | 时长: xx.xx s | 采样率: xxxx`;
- 视图自动缩放回 1×;
- 多选或连续导入的文件都会保留在左侧列表中,点击文件名即可切换,**切换无需重新分析**(结果已缓存);
- 重复导入同一个文件会直接切回它,不会产生重复条目。

## 4. 录音

1. 点击工具栏 **录音** 按钮,按钮变为"停止录音",状态栏显示 `录音中... 设备: <设备名>`;
2. 对着麦克风发声;
3. 再次点击按钮结束,自动分析并显示录音的音高曲线(标题为 `[录音]`)。

- 录音使用系统默认输入设备,16 kHz 单声道;
- 每段录音以 `[录音 1]`、`[录音 2]`… 的名称保留在左侧文件列表中,可随时点击切回查看(与文件一样免重新分析);
- 没有可用麦克风时弹出"录音失败"提示;
- ⚠ 录音结果当前无法导出为音频文件,关闭程序后丢失(改进计划见 roadmap)。

## 5. 缩放

提供 7 档倍率:0.25× → 0.5× → 1× → 2× → 4× → 8× → 16×(默认 1×)。

| 操作 | 效果 |
| ---- | ---- |
| 点击工具栏 **放大** | 倍率升高(时间轴放大,单屏显示的时间更短、细节更多) |
| 点击工具栏 **缩小** | 倍率降低 |
| 拖动底部 **缩放滑块** | 直接跳到任意档位 |
| `Ctrl + 鼠标滚轮`(在曲线上) | 上滚放大 / 下滚缩小,逐档切换 |
| `Ctrl + 左键水平拖拽`(在曲线上) | 拖拽手势缩放,松手吸附到最近档位 |

工具栏中间会实时显示当前倍率(如 `2x`)。缩放只改变时间轴的显示窗口,频率轴不变;时间网格会自动加密(1 s → 0.5 s → 0.1 s)。

## 6. 选区与播放

**框选**:在曲线视图空白处按住**左键拖拽**,出现浅蓝色高亮即为选区。

**播放**:

- 点击工具栏 **播放**:有选区时只播放选区,无选区时播放整段音频;播放中按钮变为"停止",再点一次停止;
- 或在有选区时**右键**曲线视图,选择菜单中的 **播放选区**。

**播放反馈**:

- 曲线上出现红色播放头,随播放推进;
- 底部控制栏右侧实时显示当前播放位置(如 `1.234s`);
- 播放结束或点击"停止"后,播放头消失、按钮与位置标签复位。

> 播放在后台线程执行,播放期间界面保持响应。

| 操作 | 方式 |
| ---- | ---- |
| 打开文件 | `Ctrl+O` / 工具栏"打开文件" / "添加..."按钮 |

## 8. 常见问题(FAQ)

**Q:加载 mp3 报"加载失败"?**
A:mp3/m4a/aac 依赖 ffmpeg 转码。请确认用 `pixi run run` / `pixi shell` 启动(pixi 环境自带 ffmpeg);在环境外用系统 Python 运行则可能找不到 ffmpeg。

**Q:对话框里能选 .ogg,但加载失败?**
A:文件过滤器中列出了 `*.ogg`,但当前版本尚不支持该格式,后续版本处理(见 roadmap)。

**Q:曲线上有大段灰色虚线?**
A:表示对应时间段未检测到人声/发声(静音、噪声、气声等),属正常现象。

**Q:录音后声音去哪了?**
A:以 `[录音 n]` 保留在左侧文件列表中,会话内可随时切回;当前版本暂不支持导出为音频文件,关闭程序后丢失。

**Q:长时间无响应?**
A:基频分析在 UI 线程同步执行,加载很长的文件时界面会短暂卡顿;播放已改为后台线程,不再影响响应。改进计划见 roadmap。
