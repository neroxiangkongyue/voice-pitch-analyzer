# 需求文档(Requirements)

> 状态:v0.2.0。本文档描述项目的目标用户、功能需求与非功能需求,并标注各条目的实现状态。
> 需求变更时须同步更新本文档与 [CHANGELOG.md](../CHANGELOG.md)。

## 1. 背景与目标

用户(歌手、配音、语言学习者、语音爱好者)需要直观地查看一段人声的**基频(F0)随时间的变化曲线**,用于:

- 观察音高走向、颤音、滑音等演唱细节;
- 对比录音片段的音域范围;
- 辅助音准练习与发声训练。

项目目标:提供一个**开箱即用、单机、中文界面**的 Windows 桌面工具,两步内完成"导入音频 → 看到音高曲线",并支持缩放、选区、回放等基础交互。

非目标(当前版本明确不做):

- 多轨对比、频谱图 / 共振峰分析;
- 音高修正、变声等编辑功能;
- 移动端 / Web 版本。

## 2. 功能需求

### FR-1 音频导入(已实现)

- FR-1.1 支持从文件对话框选择一个或多个音频文件(`Ctrl+O` 或"打开文件"/"添加...")。
- FR-1.2 支持将文件从系统拖拽到主窗口或曲线视图完成导入。
- FR-1.3 支持格式:`wav`、`flac`(原生);`mp3`、`m4a`、`aac`(经 ffmpeg 转码)。
- FR-1.4 加载完成后自动完成基频分析并刷新曲线,状态栏显示文件路径、时长与采样率。
- FR-1.5 加载失败(格式不支持、文件损坏等)时弹出错误对话框,不崩溃。

### FR-2 基频提取与可视化(已实现)

- FR-2.1 使用 pYIN 算法逐帧估计基频,搜索范围 50–500 Hz。
- FR-2.2 曲线视图纵轴为频率、横轴为时间;发声帧绘制为蓝色实线,未发声帧绘制为底部灰色虚线。
- FR-2.3 频率轴范围根据检测结果自动适配(5%/95% 分位数 + 10% 边距,夹取在 50–2000 Hz)。
- FR-2.4 时间与频率网格线密度随缩放级别自适应,并带有刻度标签。
- FR-2.5 视图左上角显示当前文件名(或"[录音]"),右下角显示当前显示时长。

### FR-3 缩放(已实现)

- FR-3.1 提供 7 档缩放:0.25× / 0.5× / 1× / 2× / 4× / 8× / 16×,默认 1×。
- FR-3.2 提供四种缩放入口:工具栏"放大/缩小"按钮、控制栏滑块、`Ctrl+滚轮`、`Ctrl+左键水平拖拽`。
- FR-3.3 工具栏显示当前倍率(如 `1x`);缩放改变时间轴显示窗口(`显示时长 = 总时长 ÷ 倍率`),频率轴不变。

### FR-4 时间选区(已实现)

- FR-4.1 在曲线视图上按住左键拖拽,框选一段时间区间,以半透明蓝色高亮。
- FR-4.2 选区时间随缩放/重绘保持(以时间戳存储,而非像素)。

### FR-5 播放与播放头(已实现)

- FR-5.1 点击"播放"按钮:存在选区时播放选区,否则播放全部音频;再次点击停止。
- FR-5.2 在有选区时右键曲线视图,弹出"播放选区"菜单项。
- FR-5.3 播放期间曲线视图内显示红色播放头,控制栏实时显示当前播放位置(精确到毫秒);播放头位置为音频时间轴绝对时间,选区播放时同样正确。
- FR-5.4 播放在后台线程执行,不阻塞界面;播放结束(含自然播完)或停止后,按钮、播放头与位置标签自动复位。

### FR-6 麦克风录音(已实现)

- FR-6.1 点击"录音"按钮开始录音(默认输入设备,16 kHz 单声道),按钮切换为"停止录音",状态栏显示设备名。
- FR-6.2 再次点击结束录音,自动对录音内容执行基频分析并展示,标题显示"[录音]"。
- FR-6.3 无可用输入设备时弹出错误对话框。
- FR-6.4 录音为空时状态栏提示"录音为空"。

### FR-7 文件列表(已实现)

- FR-7.1 左侧面板提供"音频文件列表"与"添加..."按钮。(已实现)
- FR-7.2 列表管理会话内多个已导入文件与录音(`[录音 n]`),点击切换;重复导入同一文件直接切换,不重复分析;切换时复用缓存的分析结果。(已实现)

## 3. 非功能需求

| 编号 | 类别 | 需求 | 状态 |
| ---- | ---- | ---- | ---- |
| NFR-1 | 平台 | 仅支持 Windows 10/11 x64 | 已实现 |
| NFR-2 | 易用性 | 简体中文界面;两步内完成"导入 → 看曲线" | 已实现 |
| NFR-3 | 部署 | 依赖由 pixi 一键创建,ffmpeg 随环境安装,用户无需手工配置 | 已实现 |
| NFR-4 | 健壮性 | 格式错误、空文件、录音失败等异常不得导致崩溃 | 已实现 |
| NFR-5 | 响应性 | 播放在后台线程执行,不阻塞界面;基频分析仍在 UI 线程同步执行,长音频加载期间界面可能短暂无响应(改善计划见 roadmap) | 部分满足 |
| NFR-6 | 精度 | pYIN 搜索范围 50–500 Hz,覆盖绝大多数人声基频 | 已实现 |

## 4. 验收标准(示例)

- 导入 3 分钟 `mp3` 文件,10 秒内完成加载与分析(取决于机器性能),曲线完整显示。
- 缩放到 16× 后,时间网格自动细化到 0.1 s,网格标签不重叠出界。
- 框选任意区间后点击"播放",仅播放选区内容。
- 录音 5 秒后停止,界面出现录音内容的音高曲线,时长约 5 s。
- 拖入一个 `.txt` 文件,弹出"加载失败"对话框,应用继续可用。
